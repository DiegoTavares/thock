Install on macOS

  1. Open the .dmg and drag Thock into Applications.
  2. Launch it. If macOS says the app is from an unidentified developer, right-click it once and choose Open; that only happens on a build that wasn't notarized.
  3. Point it at a folder of Markdown, new or the one you already keep. Thock adds a readable routines/ folder beside your notes and touches nothing else.

Install on Linux

  1. Extract the tarball anywhere: tar -xzf thock-linux-x86_64.tar.gz.
  2. Run thock.app/bin/thock. Updates install into the same folder.

Check the download, if you like

Every build's checksum is published with it. Compare before you open:

shasum -a 256 ~/Downloads/Thock-aarch64.dmg

Before you start

Thock runs on your own LLM: connect Claude Code, Gemini CLI, or any agent that reads AGENTS.md, with your own key. Your vault never leaves your machine, and everything the app adds is a plain file you can open, edit, or delete.

# What your agents keep

_This folder is a mirror of the memory your other agents keep for themselves:
one folder per agent and per machine, `claude-code/robin/`, `codex/hp/`. The
files are theirs; Thock copies them here one way, so they are searchable,
part of your history, and readable by the Reflect ritual, which may file a
fact about you from them with its source. Nothing here is edited by Thock or
by the desk agent; edit the originals on the machine they came from, or
delete a folder here when you disconnect that machine._

_Empty until an agent's memory is pointed at its mirror folder:
`thock-bridge connect claude` offers that for Claude Code._

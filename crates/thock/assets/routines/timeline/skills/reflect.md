# Reflect

This is the core [Reflect](../../../skills/thock/reflect.md) ritual, run on its own from the Routines panel. Read `skills/thock/reflect.md` at the vault root and execute it in **standalone** mode: the period is the daily notes since the last Reflect (up to 14 days, or the last 3 days when nothing records one), and everything else in that file, from what counts as a source to the shape of `memory/index.md`, applies unchanged.

The daily and weekly closures call the same ritual as their last step, so running this by hand is for the days that had no wrap and the weeks that had no review.
